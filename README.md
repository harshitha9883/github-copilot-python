# Sudoku Web Application

A modern, interactive Sudoku puzzle app built with Python Flask and vanilla JavaScript.

## Features
- Real-time backtracking solver & puzzle generator
- Interactive timer and hint controls
- Responsive 9x9 game grid

## Setup
1. pip install -r requirements.txt
2. python app.py
3. Open http://127.0.0.1:5000 in your browser.
